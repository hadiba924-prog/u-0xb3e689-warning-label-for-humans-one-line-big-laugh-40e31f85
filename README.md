Entry for the [make.fun bounty "Warning Label for Humans: One Line, Big Laugh"](https://make.fun/bounty/u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85): the funniest single-line safety warning label that should come printed on every human being, 160 characters or fewer.

## The label

> WARNING: This human will nod like they understood, then Google it in the bathroom.

## Why this line

It reads like a real printed warning, it is true of almost everyone, and the joke turns on the last three words: the polite nod in public, the secret search in private.

## How it works

`main.ts` (Node 22, standard library only) writes the label to `entry.txt` in the output directory (`$MAKEFUN_OUTPUT_DIR`, default `/output`).

```sh
node main.ts
```
